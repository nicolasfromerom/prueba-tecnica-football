# Instrucciones para Codex
Leer primero [.specify/memory/constitution.md](.specify/memory/constitution.md) y [specs/README.md](specs/README.md). Leer el spec, plan, tasks y pruebas de la responsabilidad antes de editar. Ejecutar una sola tarea pendiente, respetar dependencias, revisar git status y diff, validar criterios, registrar resultado y marcar tarea localmente después de su commit. No marcar pruebas no ejecutadas como aprobadas. Si falla una validación, corregir antes de avanzar; si hay bloqueo, informar. No modificar cambios ajenos ni hacer push sin autorización. No crear commits vacíos ni agrupar funcionalidades. No implementar opcionales salvo los expresamente autorizados en la constitución. No inicializar repositorios anidados.

Antes de cualquier git add, configurar las exclusiones locales descritas en specs/000-development/plan.md. Leer esa responsabilidad primero. No versionar AGENTS.md, specs/, .specify/ ni evidencias internas. No mencionar planificación interna en commits o README de aplicación. Revisar git diff --cached --name-only antes de cada commit. Ejecutar comandos PHP, Composer y npm dentro de Docker.
